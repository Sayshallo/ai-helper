# AI-помощник для подготовки товарных описаний

## О проекте
AI-помощник - приложение для автоматической подготовки черновиков карточек товаров
Программа принимает JSON-файл с информацией о контрольно-измерительном приборе, отправляет данные в Gemini и формирует результат, который можно использовать как основу для товарной карточки

## Возможности
- Генерация SEO-заголовка длиной до 70 символов
- Генерация SEO-описания длиной 800–1200 символов, если исходных данных достаточно
- Формирование списка характеристик товара
- Генерация 3–5 поисковых запросов
- Формирование commercial-блока для менеджера
- Выявление отсутствующих характеристик с помощью поля expected_specs
- Проверка структуры JSON и полученного результата
- Проверка сохранности исходных технических характеристик
- Повторная отправка запроса к модели при обнаружении ошибок

## Используемые технологии
- Python
- Tkinter
- Google Gemini API
- google-genai
- python-dotenv
- JSON

## Установка и запуск
Для работы проекта необходим Python 3.12 или новее.
1. Склонируйте репозиторий или скачайте проект.
2. Создайте виртуальное окружение:
python -m venv .venv


3. Активируйте виртуальное окружение.
Windows:
.venv\Scripts\activate

4. Установите необходимые библиотеки:
pip install google-genai python-dotenv

5. Создайте файл .env в корневой папке проекта. Скопируйте в него содержимое .env.example и укажите свой API-ключ Gemini:
GEMINI_API_KEY=example_key

6. Перейдите в папку app:
cd app

7. Запустите приложение:
python main.py

## Формат входных данных
Программа принимает JSON-файл со следующими полями:
- name - название товара
- manufacturer - производитель
- specs - характеристики товара
- expected_specs - необязательный список характеристик, значения которых желательно получить
- description - описание товара или фрагмент технического паспорта

Пример:
{
    "name": "Манометр показывающий DM 02",
    "manufacturer": "Манотомь",
    "specs": {
        "диапазон измерений": "0–1,6 МПа",
        "класс точности": "1,5",
        "присоединение": "G1/2"
    },
    "expected_specs": [
        "Материал корпуса",
        "Рабочая температура"
    ],
    "description": "Прибор предназначен для измерения избыточного давления."
}
Количество и названия характеристик могут отличаться в зависимости от типа прибора

## Формат результата
Программа возвращает JSON со следующими основными разделами:

- seo_title - SEO-заголовок
- seo_description - SEO-описание
- characteristics - список характеристик товара
- search_queries - поисковые запросы
- commercial_block - информация для менеджера
- missing_data - отсутствующие характеристики и данные
- warnings - предупреждения и ограничения генерации

## Важные ограничения
Программа создает черновик товарной карточки, а не готовую техническую документацию
Модель не должна самостоятельно дополнять технические характеристики, изменять значения или использовать внешние источники для получения недостающих данных
Перед публикацией карточки необходимо проверить результат и подтвердить техническую информацию по документации производителя
